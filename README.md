# Yoga Club OM 🧘‍♀️

A modern, responsive website for Yoga Club OM, a yoga studio in Moscow that has been helping people improve their lives through practice since 2014. This is a beautiful, performant web application built with cutting-edge technologies.

## 🌟 Features

- Modern, responsive design optimized for all devices
- Interactive class schedule
- Location integration with Yandex Maps
- Performance optimized with Next.js and Turbopack
- Beautiful UI components built with Radix UI
- Form handling with React Hook Form and Zod validation
- Analytics integration with Google Analytics and Yandex Metrika
- Email functionality with SendGrid
- Carousel components for showcasing content
- SEO optimized with Next.js metadata

## 🛠️ Tech Stack

- **Framework:** Next.js 15 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** Radix UI
- **Forms:** React Hook Form + Zod
- **Maps:** Yandex Maps
- **Analytics:** Google Analytics + Yandex Metrika
- **Email:** SendGrid
- **Performance:** Turbopack

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/yogaclubom.git
cd yogaclubom
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
# or 
bun install # recommended
```

3. Set up environment variables:
Create a `.env.local` file in the root directory and add necessary environment variables (see `.env.example` for reference).

4. Run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or 
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.
